# ميزان | MIZAN AI
نظام ذكاء اصطناعي للتحقق من المعلومات الدينية والتاريخية: «ما الدليل؟ ومن أين جاء؟ وهل نُقل بأمانة؟ وهل يوجد خلاف معتبر؟»
> أداة مدعومة بالذكاء الاصطناعي، وليست مفتيًا ولا بديلًا عن العلماء.

## التشغيل
```bash
npm install && cp .env.example .env   # املأ GEMINI_API_KEY (مجاني) و JWT_SECRET
npm start                              # http://localhost:3000
```
- **الدخول**: بريد إلكتروني ← كود 6 أرقام مختلف لكل محاولة (صالح 10 دقائق، 5 محاولات، يُخزَّن مُجزّأً في الذاكرة فقط). بدون SMTP يظهر الكود في الـ console.
- **النشر المجاني**: Render (Web Service: `npm install` / `npm start`) وأضف متغيرات البيئة.
- **اللغات**: العربية، English، Français، Deutsch، Español، Português، हिन्दी، 日本語، 中文.

## مطابقة معايير التحكيم
| المعيار | الوزن | كيف يتحقق |
|---|---|---|
| جودة الحل التقني وتوظيف الذكاء الاصطناعي | 25% | LLM بمخرجات JSON منظمة + حواجز ما بعد التوليد (تنقية الروابط، فرض الإحالة) + حدود طلبات |
| الموثوقية والسلامة العلمية | 15% | مستويات أ/ب/ج/د، مصادر الحزمة فقط، امتناع عند ضعف الدليل، منع الاختلاق، الإحالة في الفتاوى الشخصية |
| الابتكار والقيمة المضافة | 15% | بطاقة توثيق لكل إجابة، وضع «تحقق من نص» (تفكيك لادعاءات)، مؤشر ثقة، مستويات إجابة |
| تجربة المستفيد والتواصل والإتاحة | 10% | 9 لغات + RTL، تباين وتركيز لوحة مفاتيح، وضع داكن، خطاب محترم |
| تحقيق النفع وفق معيار المسار (4) | 20% | يُظهر المصدر وحالة الدليل ويميّز المؤيَّد مما يحتاج تحققًا (انظر `tests/`) |
| واقعية التشغيل والاستكمال | 10% | كله مجاني (Gemini free tier + Gmail SMTP + Render)؛ صيانة: مراجعة القائمة البيضاء للمصادر دوريًا |
| وضوح العرض وإتاحة التحقق | 5% | روابط المصادر قابلة للفتح، وملف الاختبارات قابل للإعادة |

## الاسترجاع من المصادر (RAG)
- **الحديث**: يُجلب نصه وراويه ومحدّثه ومصدره وصفحته وخلاصة حكمه من واجهة الدرر السنية (dorar.net)؛ النموذج لا يكتب نص حديث أبدًا، بل يختار من النتائج فقط.
- **القرآن**: كل آية يذكرها النموذج يُستبدل نصها بالرسم العثماني من api.alquran.cloud ويظهر ✓ (أو ⚠ إن تعذر التحقق).
- **المكتبة الشاملة**: زر 📖 بجانب أي مرجع رابطه shamela.ws يفتح نص الصفحة داخل التطبيق عبر `/api/shamela`.

## الضوابط (المعيار العلمي الملزم)
الإسناد · التمييز بين القطعي والاجتهادي · عدم الاستقلال بالفتوى · مقاومة الهلوسة · الجودة الدعوية · الترجمة والتوطين · الشفافية (تنبيه AI) · الخصوصية (لا تخزين للأسئلة، البريد مُجزّأ).

## المصادر المعتمدة (سجل المصادر)
القرآن: مجمع الملك فهد / quranpedia.net · التفسير والسيرة والعقيدة: dorar.net · الحديث: الصحيحان ثم dorar.net/hadith وshamela.ws مع الحكم · الفقه: dorar.net/feqhia · الدعوة والمصطلحات: dawa.center وislamic-content.com. الروابط خارج هذه القائمة تُحذف تلقائيًا.

## حدود معروفة
نموذج لغوي قد يخطئ؛ لذلك يضع التطبيق «يحتاج تحققًا» على أي مرجع بلا صفحة، ويمتنع عند غياب الدليل. التوصية: ربط بحث حقيقي (RAG) على نصوص دورر/الشاملة في مرحلة لاحقة.

## تشغيل خطوة بخطوة (Windows/Mac)
1. ثبّت Node.js (18+) من nodejs.org، ثم داخل مجلد المشروع: `npm install`
2. أنشئ `.env` من `.env.example` وضع فيه مفتاح Gemini وJWT_SECRET (أي نص طويل عشوائي). **لا ترفع `.env` على GitHub** (موجود في .gitignore).
3. `npm start` ← افتح http://localhost:3000 (كود التأكيد يظهر في الـ console لو لم تضبط SMTP).
4. اختبار الحالات الـ12 (والسيرفر شغال في نافذة أخرى): `npm run eval` ← `tests/report.md`
5. فهرسة كتبك: ضع الـ PDFs في `books/` ثم `npm run index` (OCR عبر Gemini، يُستكمل لو توقف).

cd mizan-mobile && npx expo install react-native-webview
# انسخ mobile/App.js فوق App.js ثم:
